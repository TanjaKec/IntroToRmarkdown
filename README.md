# R Markdown + GitHub Workshop

This repository is designed for a hands-on workshop introducing R Markdown and basic Git/GitHub workflows.

## Overview

In this workshop, participants will learn how to:

- Create and edit an R Markdown document
- Format text using Markdown syntax
- Add links and lists
- Embed and run R code
- Control output using chunk options (`eval`, `echo`)
- Create simple plots using `ggplot2`
- Include mathematical equations using LaTeX
- Use GitHub Desktop to track and share their work

## Repository contents

- `RMarkdown_Intro.Rmd`  
  Starter R Markdown file for participants to edit during the workshop.

- `workshop_tasks.pdf`  
  Step-by-step instructions guiding participants through the tasks.

## Getting started

1. Clone this repository using GitHub Desktop or RStudio.
2. Open `RMarkdown_Intro.Rmd` in RStudio.
3. Follow the instructions in `workshop_tasks.pdf`.
4. Make changes, commit them, and push them to GitHub.

## Requirements

You will need:

- R
- RStudio
- Internet connection (for installing packages if needed)

## Notes

- Some R packages (e.g. `palmerpenguins`, `ggplot2`) will be installed automatically when running the code.
- Messages and warnings may appear when running code — these are normal and can be controlled using chunk options.

Happy coding!
